使用说明网站作者：听雨说星星的故事

本网站旨在为鱼丁们创造一个可以时刻回顾禹欣的很多「值得纪念的美好事件」的环境，以下为使用说明：

小提示

本网站目前分为两种模式：1.如果网络可以连接云端，右上角会显示“已同步云端”，此时内容将会实时更新，所有操作也都会同步到云端。

2.如果网络受限、无法连接云端，网站会自动加载预先放置的数据包，右上角会显示“离线数据已就绪”，数据无法实时同步，但仍然可以正常浏览全部内容。

数据包会不定期更新，以保证离线用户也能看到最新版本的内容。

1. 浏览时间线

进入网站后，可以直接通过时间线查看已经记录的事件。使用“密度”可以调整节点间距；“滑速”用于调整鼠标进入时间线左右边缘时的自动滚动速度，也可以使用滚轮和两侧按钮浏览更早或更晚的内容。

2. 预览与事件详情

将鼠标悬停在时间线节点附近可以查看事件预览；点击节点即可进入详情，详情中可以先查看该事件收录的图片、动图、视频和网址附件，再阅读详细经过与描述。

3. 查看媒体与深入描述

详情中的图片、动图和视频可以进一步查看；如果某个媒体启用了“深入描述”，可以进入对应空间浏览额外的文字、媒体与区域联结。

4. 节点之间的逻辑关系

部分事件之间存在逻辑连线或关联。在时间线上查看相关节点时，可以结合节点之间显示的连接关系理解事件之间的前后、补充或关联关系。

5. 搜索事件

使用时间线右侧的搜索框输入事件标题并确认，可以快速定位对应节点。

6. tag功能

打开 tag 库后可以按 tag 筛选时间线内容，并可选择“包含 / 排除”以及“任一 / 全部”等匹配方式，筛选生效后，时间线只会显示符合当前筛选条件的事件。

7. 背景音乐

顶部“背景音乐”可以播放网站设置的背景音乐。播放有声视频时，背景音乐会自动暂停；视频停止后会根据原来的播放状态恢复。

另：想自己上手编辑的话可以call作者给权限喵

小tips

在编辑界面内，如果某个区域存在单独的“保存 / 添加 / 确定”按钮，一定要记得点击，例如逻辑连线处、网址附件处等；不点击的话，对应内容不会保存。

1. 新建事件

解锁编辑权限后，可以点击右上角“新建事件”创建新的时间线事件；已有事件也可以打开后继续修改。

2. 填写事件名称

在事件名称处填写这条事件在时间线上显示的标题。建议使用能够快速辨认内容的名称，之后也可以通过搜索框按标题查找事件。

3. 填写日期及日期范围

根据事件实际情况填写日期。如果事件只发生在某一天，可以填写单个日期；如果不知道具体日期，也可以只填写月份或年份；如果持续了一段时间，则可以设置开始和结束日期，让时间线按对应时间范围展示。

4. 选择节点类型

节点类型会影响事件在时间线上的呈现方式。根据事件性质选择合适的节点类型即可，之后仍然可以重新编辑调整。

5. tag 功能

tag功能可以帮助整理和筛选事件。可以打开 tag 库创建新的 tag，也在编辑事件时为事件添加一个或多个 tag。

6. 逻辑连线

逻辑连线用于表示两个事件之间存在关联。编辑事件时，可以在逻辑连线区域选择要连接的其他事件，也可以填写连线文字作为关系的补充说明，并设置这条关系。

7. 添加图片、动图与视频

可以为事件添加图片、动图和视频，也可以调整其顺序。图片可以进行截选；视频可以设置标题并截取画面作为预览封面。需要进一步补充分析时，还可以为对应媒体进入“深入描述”空间进行编辑。

8. 添加网址附件

可以填写网址标题和链接，将网页作为事件的补充附件添加进去。已经添加的网址附件之后也可以继续修改标题或链接，也可以删除不再需要的附件。

9. 详细经过与描述

“详细经过与描述”用于记录事件本身更完整的经过、背景、补充说明或想法。编辑时支持多种文字样式，可以根据内容需要进行排版。

10. 背景音乐

顶部“背景音乐”用于添加音频链接并管理网站的背景音乐播放。

11. 分享协同

“分享协同”仅在编辑模式且云端连接正常时使用。可以复制当前空间的专属链接发送给其他人，让不同设备进入同一个空间查看和协作编辑内容。
